# Новое промышленное ателье

Сайт предприятия: термочехлы для промышленного оборудования, чехлы и обивка транспортных кресел, пошив чехлов и элементов обивки для производителей мебели.

## Текущая версия

- Сравнение промышленного оборудования до и после установки термочехлов с перетаскиваемым разделителем.
- Шесть состояний обивки кресла: каркас, подголовник, спинка, подлокотники, сиденье, опора для ног. Затем включаются вращение и крупные планы.
- Общая форма подготовки письма. Автоматической отправки и серверного приёма заявок пока нет.
- Мебельный раздел пока представлен эскизом. Для дальнейшей разработки согласованы категории: домашняя мебель, офисная мебель, мебель для ресторанов, «Для отелей» (обивка для кроватей, чехлы для матрасов и постельное бельё).
- Отдельный предварительный просмотр образцов мебели: `dist/furniture.html`. Три мебельные категории переключают мебельные группы в гостиной, офисе и банкетном зале; формы и базовые ткани ещё согласуются. В каждой сцене три кружка открывают отдельные крупные планы ткани и соединений; те же детали доступны из карточек под изображением. Четвёртая вкладка «Для отелей» содержит три группы текстильных изделий и переход к форме с выбранным гостиничным направлением; прямой вход — `dist/furniture.html#hotel`.

## Как посмотреть

Для простого просмотра откройте `dist/index.html` в браузере. Папка `dist/assets` и остальные файлы должны оставаться рядом.

Для работы через локальный сервер из корня репозитория:

```sh
python -m http.server 4177 --bind 127.0.0.1 --directory dist
```

Откройте <http://127.0.0.1:4177/>. На системах, где Python запускается как `python3`, используйте это имя команды.

## Проверки

Нужен Node.js 18 или новее. Сторонних пакетов нет, установка зависимостей не требуется.

```sh
npm test
```

Проверяются ресурсы и ссылки, последовательность кадров и момент включения вращения, атрибуты видимости SVG, остановка показа вне экрана, управление креслом, крупные планы, уменьшенное движение, ошибки загрузки, сравнение термочехлов и подготовка письма.

## Структура

```text
dist/             Статические файлы сайта и изображения
scripts/          Проверки без сторонних зависимостей
.openai/          Конфигурация существующего размещения в Sites
package.json      Команда запуска проверок
```

Сайт не требует сборки: для размещения используются файлы из `dist/`. Локальная версия не означает, что изменения уже опубликованы на внешнем адресе.

Исходные фотографии, переписка, внутренние документы предприятия, летопись общего проекта, резервные копии и ZIP для отправки на проверку хранятся отдельно от этого репозитория.
